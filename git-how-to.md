# 🚀 Шпаргалка по работе с SSH и GitHub

Краткое руководство по созданию SSH-ключей, их добавлению на GitHub и клонированию репозиториев.

---

## 1. Как создать SSH-ключ

Выполните команду в терминале (Git Bash на Windows, Терминал на macOS/Linux). 
Вместо `your_email@example.com` укажите почту, привязанную к вашему GitHub.

```bash
ssh-keygen -t ed25519 -C "your_email@example.com"
```
*Примечание: Если ваша система не поддерживает алгоритм Ed25519, используйте: `ssh-keygen -t rsa -b 4096 -C "your_email@example.com"`.*

### Что делать дальше:
1. Терминал предложит выбрать место сохранения (`Enter file in which to save the key`). Просто нажмите **Enter** (выберется путь по умолчанию).
2. Терминал предложит ввести кодовую фразу (`Enter passphrase`). Если хотите дополнительную защиту, введите пароль. Если нет — дважды нажмите **Enter**.

---

## 2. Как добавить ключ в аккаунт на GitHub

### Шаг 1: Скопируйте публичный ключ в буфер обмена
Вам нужен файл с расширением `.pub`. Выведите его содержимое в терминал и скопируйте:

* **Windows (в Git Bash):** `cat ~/.ssh/id_ed25519.pub`
* **macOS:** `pbcopy < ~/.ssh/id_ed25519.pub` (сразу скопирует в буфер)
* **Linux:** `cat ~/.ssh/id_ed25519.pub`

### Шаг 2: Добавьте ключ на сайте
1. Перейдите на **GitHub** и войдите в аккаунт.
2. В правом верхнем углу нажмите на свое фото профиля -> **Settings** (Настройки).
3. В левом меню выберите **SSH and GPG keys**.
4. Нажмите кнопку **New SSH key**.
5. В поле **Title** введите понятное название (например, *My Laptop*).
6. В поле **Key** вставьте скопированный ранее текст ключа.
7. Нажмите **Add SSH key**.

> 💡 **Проверка связи:** Выполните в терминале команду `ssh -T git@github.com`. Если всё сделано правильно, вы увидите сообщение: *Hi [Ваш логин]! You've successfully authenticated...*

---

## 3. Как склонировать репозиторий

1. Откройте нужный репозиторий на GitHub.
2. Нажмите зеленую кнопку **Code**.
3. Убедитесь, что выбрана вкладка **SSH**, и скопируйте ссылку (она выглядит как `git@github.com:username/repository.git`).
4. В терминале перейдите в папку, куда хотите скачать проект (например, `cd Documents`).
5. Выполните команду:

```bash
git clone git@github.com:username/repository.git
```
